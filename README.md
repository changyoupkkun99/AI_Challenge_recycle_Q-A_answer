## 📌 1. 대회 개요 (Overview)

이미지 속 세상을 **'읽고, 이해하고, 답하는'** 인공지능, 바로 **VQA(Visual Question Answering)** 모델은 인간의 시각적 사고에 가장 가까운 형태의 AI 기술입니다.  
본 챌린지는 재활용품 이미지와 텍스트(질의응답)를 함께 이해하는 **멀티모달 인공지능(Multimodal AI)**을 직접 개발하고 평가하는 대회로, 실제 환경에서 활용 가능한 AI 모델을 개발하며 인공지능 기술 역량을 강화하는 것을 목표로 합니다.

<br/>

### 💡 VQA 모델이 필요한 이유
* **시각 정보 해석 능력의 확장**: 단순 인식을 넘어 *"이 이미지에 뭐가 있지?"*, *"이 장면은 어디일까?"* 같은 질문에 답하며 **'이해'** 단계로 진입합니다.
* **실제 서비스 적용 가능성**:
  * 🏭 **스마트 팩토리**: 영상 데이터 기반 품질 이상 탐지 및 설명
  * 🏥 **의료 영상 분석**: 진단 보조를 위한 시각적 질의응답
  * 🚗 **자율주행 및 CCTV**: 상황 인식 및 위험 상황 설명
  * ♿ **교육 및 접근성**: 시각장애인을 위한 이미지 설명 AI
* **멀티모달 러닝의 핵심**: ChatGPT, Gemini, Claude 등 최신 멀티모달 모델과 동일한 아키텍처 원리를 직접 구현 및 체득할 수 있습니다.

## 🎯 2. 대회 미션 & 데이터셋

### 📝 미션 내용
주어진 **재활용품 이미지**와 **자연어 질문**을 입력받아, 선지(`a`, `b`, `c`, `d`) 중 올바른 정답을 도출하는 4지선다형 VQA 모델을 구축합니다.

### 📊 데이터셋 구성
* 데이터 수집 미션을 통해 확보된 이미지 중 일부를 퀴즈 형태로 가공
* **이미지 + 질의응답(Question-Answering) 쌍** 데이터 제공

> **예시 데이터:**
> * **질문**: 바구니 속에 든 재활용품은 어떤 소재인가요?
> * **선지**: `a. 캔` | `b. 병` | `c. 플라스틱` | `d. 비닐`
> * **정답**: `c`

## ⚙️ 3. 개발 프로세스 가이드

1. **Model Selection**: 다양한 사전 학습 모델 성능 비교 및 베이스라인/최적 모델 선정 (예: `Qwen-VL`, `LLaVA`, `BLIP` 등)
2. **Data Augmentation**: 재활용품 도메인 특성에 맞춘 이미지 증강 기법 적용
3. **Fine-tuning**: 다운스트림 VQA 태스크 및 제공 데이터셋 포맷에 맞춘 파인튜닝
4. **Prompt Engineering**: 추론(Inference) 정확도 극대화를 위한 프롬프트 최적화
